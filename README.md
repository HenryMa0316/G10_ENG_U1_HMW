# G10_ENG_U1_HMW
# Why Are Gen Z Not Growing Up

A single-file interactive narrative game exploring structural barriers faced by Gen Z instead of personal failure.

## Theme
Gen Z isn't “refusing to grow up,” and this game isn't about laziness (I'm not blaming teenagers).  
The thresholds of adulthood have been structurally raised.  
It is a simulation of compressed trial-and-error space, milestones, and the labour of care, debt, and structural inequality.
This game shows the pressure through:
- Daily life nodes
- Card draws that consume “Room”
- Real data on housing, debt, caregiving, employment, and so on
- Timeline comparison (expected age and actual age)
- Player-defined milestones

## Three paths:
- | Tyler | Local: lack of direction & soft expectations |
- | Wei   | Immigrant: compressed by parental sacrifice |
- | Kaya  | Indigenous: early responsibility & systemic weight |

## How to Play
1. Choose a character  
2. Read the background
3. Set your own expected ages for 5 milestones  
4. Progress through 10 daily nodes  
5. Optionally draw cards (Small / Medium / Large / Boss), which cost different amounts of "Room"
6. Reach the ending: timeline + optional hidden ending + self reflection

## Technical Notes
- Single HTML file — pure front-end, zero dependencies
- All CSS & JavaScript are inline
- Visual language: card UI inspired by 'Sanguosha'(a popular Chinese card game; I think it looks beautiful, so I borrowed some ideas) + neon feel from 'Balatro' (another globally popular game)

## The final message:
- Growing up was never just one thing or some traditional milestones.  
- Some timelines are blocked by society.  
- Gen Z don’t have to live by someone else’s schedule.
